Open MCT es un tablero vacío que se llena con enchufes: cada plugin conecta algo —una fuente de datos, una gráfica, una tabla— y el núcleo solo se encarga de juntar a quien pide un dato con quien lo tiene.

Es el software que usa la NASA para ver la telemetría de sus misiones. Aquí está su esqueleto en lenguaje simple, con el archivo y la línea exacta de cada pieza, para entender cómo viajaría un dato de nuestro Percy hasta una gráfica.

Y si un día quisiéramos ver a Percy en el Open MCT de verdad, el plugin se vería así. Boceto: no se instaló ni se probó en el repo

// percy-plugin.js — un plugin = una función que recibe openmct
export default function PercyPlugin() {
  return function install(openmct) {
    openmct.types.addType('percy.telemetry', { name: 'Dato de Percy' });

    // Un objeto con su ficha (metadatos): tiempo = domain, valor = range
    openmct.objects.addProvider('percy', {
      get: (identifier) => Promise.resolve({
        identifier,
        name: 'Distancia recorrida',
        type: 'percy.telemetry',
        telemetry: {
          values: [
            { key: 'utc', name: 'Tiempo', format: 'utc', hints: { domain: 1 } },
            { key: 'value', name: 'Distancia', unit: 'km', hints: { range: 1 } }
          ]
        }
      })
    });

    // El proveedor: «¿es de Percy? lo sirvo yo»
    openmct.telemetry.addProvider({
      supportsRequest: (obj) => obj.type === 'percy.telemetry',
      request: async () => {
        const res = await fetch('https://mars.nasa.gov/mmgis-maps/M20/Layers/json/M20_waypoints.json');
        const { features } = await res.json();
        return features
          .map((f) => f.properties)
          .filter((p) => p.dist_total_m > 0)
          .map((p) => ({ utc: dateFromSol(p.sol).getTime(), value: p.dist_total_m / 1000 }));
      }
    });
  };
}
  1. La clave del tiempo se llama utc porque debe coincidir con el sistema de tiempo activo de Open MCT (API.md:530).
  2. Los sols de la NASA se convierten a fecha con dateFromSol(), la misma función de ephemeris.js del juego.
  3. Como el valor tiene la pista range, Open MCT ofrece la gráfica automáticamente, y el dato recorre el mismo camino del mapa: request → PlotSeries.add → WebGL.
  4. Para el tiempo de luz en vivo se agregaría supportsSubscribe + subscribe, que debe devolver la función para desuscribirse (API.md:539).
